# 未归档档案 · THE UNFILED

一款以《旁观者》同人故事为基础的中文互动档案游戏。

## 当前版本
- 案件审查：通过选择推进记录，发现并解锁证据。
- 人物档案：卡尔、卡戎、阿尔伯特、帕特里克与玛莎。
- 关系记录：保留角色间的情感张力与原有人物方向，不把所有关系简化成单一结论。
- 结案分支：根据审查倾向产生不同的结案意见。
- 手机端适配：单页 HTML，无需安装依赖。

## 发布到 GitHub Pages
1. 打开仓库的 **Settings（设置）**。
2. 进入 **Pages（页面）**。
3. 在 **Build and deployment（构建与部署）** 中，将 Source（来源）选为 **GitHub Actions**。
4. 等待 Actions 工作流完成后，在 Pages 页面打开网站链接。

注意：发布后网页内容会公开可访问。
